Dock Preview — 安装指南
版本 0.2.0

系统要求
• Apple Silicon Mac（M1 或更新芯片）。
• macOS 27.0 或更高版本；不支持 Intel Mac 或较早的 macOS。

1. 安装
打开 DMG，将“Dock Preview.app”拖到 Applications（应用程序）快捷方式上。
更新时，请先从菜单栏退出旧版 Dock Preview，再替换“应用程序”中的应用。
复制完成后推出磁盘映像，从“应用程序”打开应用，不要直接在 DMG 中运行。

2. 首次打开
此版本使用临时签名（ad-hoc），未经 Apple 公证。
如果 macOS 因无法验证开发者而阻止打开，请先尝试启动一次，再打开
“系统设置 → 隐私与安全性”。确认下载来源可信后，点击“仍要打开”，
并确认启动。受管理的 Mac 可能不提供该选项。无需关闭 Gatekeeper 或 SIP。
Apple 官方说明：https://support.apple.com/zh-cn/102445

3. 授权
点击 Dock Preview 菜单栏图标，打开“设置与权限”。
点击“辅助功能”旁的“授权”，然后在“系统设置 → 隐私与安全性 → 辅助功能”
中允许 Dock Preview。
授权“屏幕录制”后可以显示缩略图；系统可能将该页面命名为“屏幕与系统音频录制”。
未授权屏幕录制时，仍可显示系统暴露的窗口标题卡片。
如果 macOS 提示需要重新启动应用，请退出并重新打开 Dock Preview。
系统权限需要你自行确认，应用不会代替你授权。

4. 语言
“设置 → 语言”提供“跟随系统”、English 和“简体中文”。
默认按系统首选语言选择；中文首选语言使用简体中文，其他不支持的语言回退到英文。
手动切换立即生效，并在下次启动时保留。
macOS 的系统弹窗和其他应用的窗口标题仍使用它们自身的语言。

5. 使用
悬停正在运行的应用 Dock 图标可查看窗口。点击卡片切换窗口，点击 × 请求关闭。
在确认应用没有打开或最小化窗口时，面板提供“退出应用”。
系统无法可靠提供截图时，可能显示缓存或标题卡片。
登录启动默认关闭，可在设置中开启。
预览仅保存在内存中，不写入磁盘、不上传。

排查与卸载
如果授权后仍提示不可用，请退出并重新打开应用。必要时删除旧辅助功能授权条目，
重新添加“应用程序”中的 Dock Preview。重新构建或更换签名后可能需要再次授权。
卸载时，先退出 Dock Preview，再将“应用程序”中的应用移入废纸篓。
